# 资料口径

一行产量对应一次班内试作。phase 是试作后进入本工序的阶段号，夹具变更会重开部分学习期。working_min 是在工位的经过时长，wait_min 包含其中无裁片的等待，不得再次加到班长。工装的同版实物按站点周转，排程 fixture 相同时一份夹具不能同段同时使用。导师按 mentor、day 和 shift 计公共时段，现场站点变更不能重复占其分钟。
首件仅由合格状态允许批量担单，资格按记录日订正，试用仅为观察。trace_group 是订单允许的最细整批追踪标识，max_sites 为允许承接的最大站点数。已开工产量要保存当时的承接资格，不能用更正后的资格替换历史。各站限制中的返工备用量以合格对计，不等于新订单可用库存。
